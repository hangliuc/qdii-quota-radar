## 📚 数据来源与权威性

### 一、数据来源

本报告所有数据均来自**东方财富网天天基金**（国内最大的第三方基金销售平台之一，持牌销售机构）。

| 数据项 | 来源接口 | 接口类型 | 数据权威性 |
|--------|----------|----------|-----------|
| **基金排行榜（近1年/6月收益）** | `fundapi.eastmoney.com/fundtradenew.aspx?ft=qdii` | 官方公开 API | ⭐⭐⭐⭐ 来自基金净值日度披露 |
| **净资产规模** | `fundf10.eastmoney.com/jbgk_{code}.html`（基金概况页） | 官方 f10 页面 | ⭐⭐⭐⭐⭐ 来自基金托管人披露 |
| **持有人结构（总份额 + 个人持有比例）** | `fundf10.eastmoney.com/FundArchivesDatas.aspx?type=cyrjg` | 官方 f10 接口 | ⭐⭐⭐⭐⭐ 来自基金季报/半年报/年报（法定披露） |

### 二、原始数据链条

```
基金管理人（易方达、华宝等） 
  └─► 定期披露（季报/半年报/年报） 
       └─► 中国证监会基金业协会
            └─► 天天基金（东方财富）汇总入库
                 └─► 通过公开 API 提供（本报告采集源）
```

**持有人结构**属于《公开募集证券投资基金信息披露管理办法》规定的**法定披露事项**，基金管理人每季度/半年披露一次，数据真实性受监管约束。

### 三、关于"自选/购买人数"数据的说明

**结论：公开渠道不可获取**

经多轮接口探测，确认以下事实：

1. 天天基金客户端（App/网页）显示的"自选人数"是**平台私有数据**，不对外开放 API
2. 支付宝显示的"X万人持有"同样是**平台私有数据**，无公开接口
3. GitHub 上现存的第三方"天天基金 API"项目（如 kouchao/TiantianFundApi）也**未覆盖此数据**

本报告使用的"散户持有份额"是**法定披露数据**（总份额 × 个人持有比例），与"自选人数"高度正相关但非同一指标。

### 四、方法论

1. **候选池**：从全部 QDII 中用关键词规则过滤（排除指数型、ETF 联接、商品型），保留主动管理 C 类份额（100 只）
2. **取样**：按近1年收益降序取 Top 50，覆盖绝大多数高关注基金
3. **采集**：对每只候选基金抓取最新净资产规模 + 最近一期持有人结构
4. **排序**：按散户持有份额、规模、收益分别排序，生成 4 种榜单供对比

### 五、局限性声明

- 持有人结构数据**延迟 1-3 个月**（季报披露周期），无法反映最新散户动向
- 仅覆盖近1年收益 Top 50，可能遗漏"低收益但散户持有多"的老基金
- 基金分类过滤用关键词规则，不同基金公司命名习惯差异可能导致少量漏判
- 规模和份额数据截止日期各基金不同（以每只基金最近一期季报为准）

## 📌 关于自选/购买人数

既然没有公开的自选人数 API，采用以下**代理指标**：

| 指标 | 来源 | 优点 | 缺点 |
|------|------|------|------|
| **散户持有份额** | f10 季报披露 | 法定数据，真实反映散户持有 | 延迟 1-3 个月 |
| **净资产规模** | f10 实时 | 实时性好 | 机构占比大的基金会失真 |
| **近1年收益** | 排行榜 API | 实时 | 热度 ≠ 质量 |

**推荐用散户持有份额**（= 总份额 × 个人持有比例），最接近"用户关注度"。

## 🎯 我的推荐方案

### 方案 1：动态拉取（每日更新）

**实现**：每次运行时调用 fundapi 排行榜 → 过滤出主动 C 类 → 取 Top 20

- ✅ 优点：完全自动化，跟随市场热度
- ❌ 缺点：名单每天可能微调，历史数据对比可能失准
- ⚠️ 风险：某天某只黑马基金冲上排行榜，但你完全不了解就推了

### 方案 2：动态拉取 + 稳定名单（推荐）⭐

**实现**：
1. 固定核心池（散户份额 Top 20，每月手动审查一次）
2. 每日只跟踪这 20 只
3. 排行榜数据 cache 到 `data/ranking_cache.json`，与 Top 核心池对比，有重大变化时提醒

- ✅ 优点：稳定 + 有新鲜度
- ✅ 缺点：需要一个 `refresh_active_list.py` 脚本，每月跑一次

### 方案 3：收益 Top N + 散户份额下限过滤

**实现**：每日取近1年收益 Top 30 → 过滤散户份额 > 1 亿的 → 最终 Top 20

- ✅ 优点：兼顾热度和业绩
- ❌ 缺点：散户份额数据延迟 1-3 个月
